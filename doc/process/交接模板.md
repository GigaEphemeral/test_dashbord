# 步骤交接模板

> 任务/步骤：
> 日期：
> 分支 / HEAD：
> 关联任务：
> 测试 / verify：
> 运行状态：
> 口径指针：<本步日期> 本文第 4/5 节的「未做 / 未验证 / 待补」是**当时**的状态快照，后续批次可能已消化；当前缺口口径统一看 `doc/design/details/README.md` §3.2。

# 当前进展

- 本步完成了什么；处于哪个里程碑。
- 最新 commit、测试数量、verify 结果、栈是否运行。
- 未完成/进行中的事项。

# 完成功能项

- 逐项列出交付的功能、接口、配置、面板、脚本、文档。
- 对应文件路径与提交。

# 设计逻辑

- 为什么这样做；关键取舍、边界、事务/缓存/路由/失败处理。
- 与设计规范、工程规约的关系。
- 新增配置项及其默认值/覆盖方式。

# 存在缺陷项&TODO

- 本步发现的缺陷、评审 Minor、已知限制。
- 后续任务需要修复/补测的项目。
- 硬编码配置清理项（路径/超时/TTL/池大小等）。

# 待定事项和注意事项

- 下一步是什么；依赖/风险。
- 运行/调试注意事项；安全边界；数据状态。
- 需要用户决策或确认的事项。

# 附录（可选）

- 启动/验证命令、关键 URL、提交列表、关键文件、证据路径。
