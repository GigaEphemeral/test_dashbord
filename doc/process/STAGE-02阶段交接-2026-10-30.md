# 设计逻辑（收口口径）

1. **单一事实源**：实例 JVM 配置只在 `lab_instance_config`；“实例与 JVM”页与向导第 3 步共用同一编辑器。
2. **状态分离**：目标/回读/配置状态（DRAFT/PENDING_RESTART/APPLYING/APPLIED/ROLLED_BACK/FAILED/DEGRADED）分开展示；
   缺数据一律 `NO_DATA/DEGRADED/UNWIRED`，不补 0、不伪造 PASS。
3. **受控变更**：应用/回滚/重启均走同一受控重建与 10 项健康门禁（健康/应用探针/池/Nginx reload/Prometheus up/镜像身份），
   失败自动恢复并进入稳定期；稳定期内正式 run 被预检查阻断。
4. **报告即证据**：单次 run 报告含 run/环境/k6/分流/KPI/缺失项；导出为只读查询，不写台账。
5. **演示优先**：所有动作可暂停/可还原；不引入权限体系与生产加固。
